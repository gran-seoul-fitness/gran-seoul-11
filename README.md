# 그랑서울 피트니스 열차 (Gran Seoul Express)

그랑서울 피트니스 11월 운동 챌린지 웹페이지입니다.

- `index.html`: 페이지 전체 (디자인, 동작, 이미지가 모두 한 파일에 들어 있어요)
- 브라우저에서 `index.html`을 열면 바로 볼 수 있어요.

## 구성
1. 매표소: 이름·입주사 입력 후 승차권 발권, 웰니스레터·GX 시간표 보기
2. 승강장: 열차 출발 연출
3. 객차 6량: 1~5호차는 미션 2개씩, 6호차는 GX·파트너 중 1개 → 모두 11칸 (인증샷 → 승차권 펀칭)
4. 정차역: 4·8·11칸 완료 시 어메니티 수령 화면 (아침역 · 노을역 · 종착역 그랑서울)
5. 마이 티켓: 진행 칸 수, 객차별 완료, 어메니티 수령 현황
